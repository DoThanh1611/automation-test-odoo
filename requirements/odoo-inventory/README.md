# Requirement của odoo-inventory

Cung cấp requirement theo cấu trúc Path / Business Requirement / Expected Solution / Business Rules / Acceptance Criteria,
rồi chạy: `npm run req:import -- odoo inventory <file.md> --id=REQ-XXX`.
BR/AC được lưu NGUYÊN VĂN và khoá lại; mọi làm rõ nghiệp vụ đi vào `notes`.
